# Week 2 — Statistics, Probability & Exploratory Data Analysis

Goal for this week (see [readme.md](readme.md) for the original notes):
1. Compute mean, median, and mode, and choose the appropriate one for a given dataset.
2. Compute and interpret variance, standard deviation, and IQR.
3. Explain how outliers affect each measure differently.

| Day | Topic | Highlights |
|---|---|---|
| [Day 1](day1/) | Descriptive Statistics | Mean/median/mode, standard deviation, variance, and IQR on an income dataset; discussed when mean vs. median is the more trustworthy summary. |
| [Day 2](day2/) | Probability Simulation | Simulated 10,000 coin flips and normal-distribution sampling with NumPy; verified a hand-computed conditional probability (rolling a 5 given an odd roll) via simulation. |
| [Day 3](day3/) | Vectors, Matrices & Dot Products | Represented data as matrices, computed dot products/matrix multiplication by hand and with NumPy, and deliberately triggered and explained shape-mismatch errors. |
| [Day 4](day4/) | Outlier Detection & Categorical Distributions | Histograms, box plots, and IQR-based outlier flagging on student exam scores; count plots for categorical variables (gender, parental education). |
| [Day 5](day5/) | Cleaning & Univariate/Bivariate Analysis | Cleaned and de-duplicated a roller-coaster dataset; ran univariate analysis (value counts, histograms, KDE) and bivariate analysis (pair plot, correlation heatmap, scatter plots, grouped box plots). |
| [Mini-Project](miniproject/) | Week Checkpoint | A copy of the Day 5 notebook, kept as the week's standalone deliverable. |

## What this week covers
Week 2 moves from pure statistics (central tendency, spread, probability, linear algebra basics) into full exploratory data analysis on real datasets — detecting outliers, understanding categorical/numeric distributions, and reading relationships between variables via correlation and visualization.
