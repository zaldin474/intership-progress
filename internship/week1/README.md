# Week 1 — Python & Data Fundamentals

Foundational week: environment setup, core Python, then the core scientific-Python stack (NumPy → Pandas → visualization).

| Day | Topic | Highlights |
|---|---|---|
| [Day 1](day1/) | Environment Setup & Jupyter Workflow | Installed pandas/numpy/matplotlib/jupyter, froze `requirements.txt`, initialized the repo; practiced with a compound-interest calculator and simple functions (even/odd check, factorial). |
| [Day 2](day2/) | Core Data Types & Control Flow | List comprehensions, well-defined functions (`mean_min_max`), and a first class (`vehicles`) as a data record. |
| [Day 3](day3/) | NumPy — Numerical Computing | Array creation, indexing/slicing, reshaping, and vectorized/broadcast operations; Hands-On Lab building and slicing a 4x4 array. |
| [Day 4](day4/) | Pandas — Tabular Data | Loaded a FIFA World Cup 2026 dataset, inspected/cleaned it, filtered rows on multiple conditions, and aggregated stats with `groupby`; separate practice notebook repeats the fundamentals on a generic dataset. |
| [Day 5](day5/) | Data Cleaning & Visualization | Cleaned a workout dataset (missing values, an outlier typo, duplicates), derived a `Cal_Per_Min` feature with NumPy, and built/interpreted a histogram, scatter plot, and line plot. |

## What this week covers
By the end of Week 1, the environment is set up and reproducible, and the core Python + NumPy + Pandas + Matplotlib toolchain has been exercised on real (if small) datasets — data loading, cleaning, transforming, and basic visualization.
