# Week 1 - Day 2: Python's Core Data Types and Control Flow

## Goal
Practice Python's basic data types/structures, list comprehensions, well-defined functions, and simple classes.

## What was done
- Used Python's basic data types and data structures (lists, dicts).
- Used list comprehension in place of control-flow statements (if/elif/else, etc.).
- Wrote well-defined, reusable functions.
- Defined a class as a simple data record with basic methods.

## Files
- **`jupy_day2.ipynb`** — Two exercises:
  1. `mean_min_max()` — takes space-separated numbers from user input and returns a dict with their mean, min, and max.
  2. A one-line list comprehension that filters even numbers from a list (illustrating comprehension-based filtering instead of an explicit loop).
- **`week1_day2.py`** — Defines a `vehicles` class (constructor storing `name`, `model`, `year`) with a `display()` method to print the vehicle's details and a `set_year()` method to update the year. Demonstrates it by creating two vehicle objects (a Toyota Camry and a Honda CR-V) and updating one of their years.
